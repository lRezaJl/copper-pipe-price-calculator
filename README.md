# ماشین حساب قیمت لوله مسی، عایق و پرایمر (نسخه ۳.۰)

اپلیکیشن مدرن، واکنش‌گرا و آفلاین تحت وب برای محاسبه دقیق قیمت انواع لوله‌های مسی ساختمانی و صنعتی، عایق‌های برودتی و چسب‌های پرایمر ویژه فروشگاه تاسیساتی و برودتی **[فریزلنــد](https://freezeland.shop)**.

این پروژه بازطراحی کامل نسخه قبلی است که از کدهای خام JavaScript و دستکاری‌های دستی DOM به فریم‌ورک مدرن و فوق‌سریع **Svelte 5** (با سیستم جدید **Runes**) و **Vite** ارتقا یافته است. این برنامه کاملاً کلاینت‌ساید (Single Page Application) بوده و بدون نیاز به هیچ‌گونه سرور سنتی، دیتابیس یا بک‌اند، به صورت مستقیم روی **Cloudflare Workers** یا **Cloudflare Pages** با سرعت لود لبه شبکه (Edge) اجرا می‌شود.

---

## ✨ ویژگی‌های کلیدی برنامه

- ⚡ **قدرت‌گرفته از Svelte 5 با معماری Runes:**
  - محاسبات ریاضی کاملاً واکنشی (Reactive) با استفاده از `$state` و `$derived`.
  - حذف رندرهای اضافی و حجم باندل خروجی فوق‌العاده اندک (کمتر از ۳۶ کیلوبایت Gzip).
- 🎨 **رابط کاربری مدرن شیشه‌ای (Glassmorphism):**
  - پالت رنگی هماهنگ با هویت بصری فریزلند (ترکیب مس گرم `Copper` و سرمایش یخ `Ice Blue`).
  - پشتیبانی کامل از **تم تاریک و روشن (Dark / Light Mode)** با تشخیص خودکار تنظیمات سیستم‌عامل کاربر.
  - کارت‌های باثبات و تمیز بدون پرش یا تغییر رنگ ناخواسته در هاور؛ تمرکز افکت‌های تعاملی صرفاً روی دکمه‌ها و المان‌های کلیک‌پذیر.
- 🔤 **فونت فارسی ۱۰۰٪ محلی (مستقل از اینترنت بین‌الملل):**
  - ادغام فونت استاندارد **وزیرمتن (Vazirmatn)** در تمام اوزان به صورت محلی با فرمت بهینه WOFF2.
  - حذف کامل وابستگی به سرورهای گوگل فونتز (`Google Fonts`)؛ بدون تاخیر ۶۰ ثانیه‌ای تایم‌اوت در شرایط قطعی یا اختلال اینترنت در ایران و تضمین عملکرد کامل در شبکه ملی.
- 🔢 **ورودی پیشرفته نرخ واحد مس:**
  - جداسازی سه‌رقمی ارقام به صورت خودکار جهت سهولت در خواندن مبالغ بزرگ (مثلاً `53,000,000` ریال).
  - دکمه‌های استپر اختصاصی (`+` و `-`) با گام تغییر **۵ میلیون ۵ میلیون ریال**.
  - پشتیبانی از کلیدهای جهت‌نمای کیبورد (ArrowUp و ArrowDown).
- 🔗 **همگام‌سازی هوشمند متراژ لوله‌ها:**
  - دکمه کپی فوری متراژ بین لوله ۱ و ۲ برای جلوگیری از اتلاف وقت در پروژه‌های متداول با طول‌های مساوی.
- 🛡️ **محاسبه هوشمند عایق‌های برودتی:**
  - بر مبنای طول شاخه‌های استاندارد ۱.۸ متری بازار.
  - محاسبه جفتی در صورت برابر بودن متراژ لوله‌ها و محاسبه مجزا و تفکیک‌شده در صورت متفاوت بودن طول‌ها.
- 📦 **محاسبه انعطاف‌پذیر پرایمر:**
  - پشتیبانی از ۴ مدل پرایمر رایج (دور بالا، دور پایین، سفره‌ای دور بالا و سفره‌ای دور پایین).
  - محاسبه خودکار بر مبنای طول لوله و امکان تنظیم دستی تعداد در صورت متراژهای نامساوی.
- 🧾 **صدور و اشتراک‌گذاری سریع فاکتور:**
  - پیش‌نمایش اختصاصی پیش‌فاکتور با تاریخ هجری شمسی دقیق.
  - درج خودکار معادل **تومان** در انتهای فاکتور جهت تسهیل مکاتبه با مشتری.
  - دکمه ارسال مستقیم متن پیش‌فاکتور به **واتساپ** (`WhatsApp Direct`).
  - دکمه کپی متن در کلیپ‌بورد همراه با انیمیشن کانفتی (`Confetti`) و نوتیفیکیشن توست شناور.
- 📱 **پشتیبانی کامل از Progressive Web App (PWA):**
  - امکان نصب اپلیکیشن روی صفحه اصلی گوشی‌های اندروید، آیفون و ویندوز.
  - کارکرد ۱۰۰٪ آفلاین با سرویس‌ورکر مدرن و کش هوشمند فایل‌ها.
- 💾 **ذخیره‌سازی خودکار در حافظه محلی:**
  - ثبت آنی آخرین مقادیر وارد شده در `localStorage` و بازیابی خودکار با باز شدن مجدد برنامه (همراه با سازگاری داده‌های نسخه‌های گذشته).

## 🚀 راهنمای نصب و اجرای محلی (با pnpm)

پروژه به صورت کامل با پکیج منیجر سریع **pnpm** راه‌اندازی شده است (البته با `npm` نیز سازگار است).

### ۱. نصب وابستگی‌ها:
```bash
pnpm install
```

### ۲. اجرای سرور توسعه:
```bash
pnpm run dev
```
سپس آدرس محلی را در مرورگر باز کنید:
```text
http://localhost:5173/
```

### ۳. ساخت بیلد نهایی برای پروداکشن:
```bash
pnpm run build
```
فایل‌های کامپایل‌شده و فشرده درون پوشه `dist` قرار می‌گیرند.

## ☁️ نحوه استقرار روی وب (Cloudflare Deployment)

با توجه به کلاینت‌ساید بودن پروژه، نیازی به تهیه سرور لینوکسی ماهانه ندارید.

### روش اول: دیپلوی مستقیم با ورکر کلودفلر (Wrangler CLI)
فایل آماده `wrangler.jsonc` در ریشه قرار دارد. فقط دستور زیر را اجرا کنید:
```bash
pnpm run deploy
```
یا:
```bash
npx wrangler deploy
```
در صورتی که اولین بار است از Wrangler استفاده می‌کنید، دستور شما را برای ورود به حساب کاربری رایگان Cloudflare راهنمایی می‌کند و بلافاصله لینک اختصاصی اپلیکیشن به شما ارائه می‌شود.

### روش دوم: Cloudflare Pages (اتصال خودکار به GitHub)
1. سورس پروژه را در مخزن گیت‌هاب قرار دهید.
2. در پنل Cloudflare به بخش **Workers & Pages > Create > Pages** بروید.
3. مخزن خود را انتخاب کرده و تنظیمات زیر را وارد کنید:
   - **Framework Preset:** `Vite`
   - **Build Command:** `pnpm run build`
   - **Build Output Directory:** `dist`
4. با هر بار Commit در گیت‌هاب، اپلیکیشن به صورت خودکار بیلد و با اتصال به CDN جهانی کلودفلر منتشر می‌شود.
